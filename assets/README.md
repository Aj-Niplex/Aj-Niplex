# Assets

Logos and images for the portfolio site.

**Canonical copies live in** [`Aj-Niplex/Aj-Niplex.github.io`](https://github.com/Aj-Niplex/Aj-Niplex.github.io/tree/main/assets) (not deleted).

To sync binary files into this repo (GitHub API text tools cannot always push binaries cleanly):

```bash
git clone https://github.com/Aj-Niplex/Aj-Niplex.github.io.git
cp Aj-Niplex.github.io/assets/* ./assets/
git add assets && git commit -m "Sync site assets" && git push
```

Or open the site with CSS/images served from the Pages repo via relative paths after you copy them.

Files expected:
- `company_logo.png`
- `niplex_ai_logo.jpeg`
- `rei_logo.png`
- `user_logo.jpeg`
